# 👕 PrintWear Streetwear - Özel Baskı T-Shirt Mağazası

Bu proje, **Gumball, Tavşan ve Ayıcık** gibi özel arka baskılı oversize t-shirtlerin sergilendiği modern ve mobil uyumlu bir e-ticaret tanıtım sitesidir.

## 🚀 Özellikler
- **İnteraktif Arka Baskı Gösterimi:** T-shirt görsellerinin üzerine gelindiğinde ürünün arka baskısı gösterilir.
- **Modern Tasarım:** Şık renk paleti, duyarlı (responsive) kart yapısı.
- **GitHub Pages:** Ücretsiz ve canlı yayın desteği.

## 🛠️ Kullanılan Teknolojiler
- HTML5
- CSS3 (Flexbox & Grid)
- FontAwesome İkonları
- Google Fonts (Plus Jakarta Sans)
